# OpenSpace 저장소 작업 지침

## 기술 기준
- 언어: C++20
- 문자 집합: Unicode

## 코딩 스타일

- 기존 코드의 4칸 들여쓰기와 중괄호 스타일을 따른다.
- 클래스 이름은 `PascalCase`, 멤버 함수는 `PascalCase`, 멤버 변수는 `m_`으로 시작한다.
- 상수의 의미를 드러내는 이름으로 선언하고 매직 넘버 사용을 피한다.

## 작업 결과 보고

- 변경한 동작과 핵심 파일을 간단히 설명한다.
- 실행한 빌드 또는 테스트 명령과 결과를 보고한다.
- 검증하지 못한 사항이나 남은 위험이 있으면 숨기지 말고 명시한다.
